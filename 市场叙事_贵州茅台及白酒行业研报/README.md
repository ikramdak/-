## 课堂用途与边界

用这些研报提取**市场如何描述贵州茅台及白酒行业**，尤其是市场对白酒企业估值所相信的增长、价格、销量、渠道、竞争优势与风险假设。记录观点时标明报告日期、发布机构、具体页码，并区分卖方观点、市场共识假设与研究者自己的判断。

研报属于市场叙事及预期材料；其中的公司经营事实和财务数字仍须回到对应时点可得的公司公告、定期报告等一手资料核验。若用于历史时点的投资判断，不将后来发表的研报回填到当时的信息集。

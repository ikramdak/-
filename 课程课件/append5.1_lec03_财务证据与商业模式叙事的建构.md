# 财务证据与商业模式叙事的建构

**贵州茅台案例、财务验证框架与教学设计**

> **核心方法：先用财报还原企业如何运转，再用商业模式框架解释它为何成立。**
>
> 第一层叙事沿“收入—成本—资本投入—现金流”建构商业模式的经济逻辑；第二层叙事在此基础上，以“价值创造—价值交付—价值获取”解释这些经济结果如何产生。两层叙事使用同一套证据，后一层必须承接前一层的判断与边界。

## 一、课程定位：两层叙事及其递进关系

### 1.1 Lec03 的总问题与教学目标

商业模式分析首先回答一个完整问题：

> 企业向谁提供什么价值，通过什么经营系统创造和交付价值，又如何将这种价值转化为收入、利润、现金流和资本回报？

据此，Lec03 的教学目标可表述为：

> 学生首先沿着“收入—成本—资本投入—现金流”的经济逻辑，利用年度报告重建企业商业模式的财务基础，区分已核验事实、机制解释、替代解释和未知事项；在此基础上，再从价值创造、价值交付和价值获取三个环节，将分散的财务证据整合为逻辑自洽、证据可追溯且具有反证条件的商业模式叙事。

本文统一使用“商业模式叙事”，指证据约束下的商业模式解释。它包括两个递进层次：第一层说明收入、成本、资本投入与现金流如何相互关联；第二层进一步说明企业通过哪些活动与交易安排创造、交付并获取价值。叙事不是围绕既定结论挑选材料，也不是对公司宣传内容的转述。

### 1.2 两层叙事回答不同深度的问题

| 比较维度 | 第一层叙事：商业模式的经济逻辑 | 第二层叙事：价值创造—价值交付—价值获取 |
| --- | --- | --- |
| 基本结构 | 收入 → 成本 → 资本投入 → 现金流 | 价值创造 → 价值交付 → 价值获取；价值主张交代客户与价值问题 |
| 核心问题 | 企业如何赚钱、需要多少资本、利润能否变成现金 | 客户为什么购买、企业如何提供价值、如何保留其中的经济收益 |
| 主要对象 | 财务报表、年报附注、经营数量、会计口径、财务比率 | 客户需求、产品价值、生产活动、关键资源、渠道、交易与定价机制 |
| 主要优势 | 可取证、可核验、可计算、可复算 | 能解释财务结果背后的经营机制 |
| 单独使用的局限 | 容易退化为收入、毛利率、Capex、CFO 的指标清单 | 容易停留在品牌、工艺、渠道等未经验证的概念叙事 |
| 在课程中的位置 | 取证主线，也是第一层经济逻辑叙事的组织结构 | 承接第一层叙事，解释活动、资源与交易安排如何产生经济结果 |

两层之间具有递进关系。第一层先说明经济结果及其联系，第二层再还原产生这些结果的经营机制。分析可以反复回查证据，但成果表达应让学生看清这一递进：

```text
商业模式总问题
    ↓
提出客户价值与经营机制假设
    ↓
沿“收入—成本—资本投入—现金流”取证、检验并形成第一层叙事
    ↓
以“价值创造—价值交付—价值获取”解释结果，形成第二层叙事
    ↓
形成有边界、有替代解释、有失效条件的商业模式叙事
```

### 1.3 为什么保留四环节作为课程主线

四环节更具体，更容易从年报取证，也更便于连接既有课件、任务合同和后续财务分析。若将价值逻辑直接替换为新的任务主线，会出现三类问题。

**第一，增加平行框架。** 课程已经包含投研全流程、8 步判断链、任务主线和证据状态分类，再引入一套并列的操作框架，容易使学生不知道应按哪套结构完成作业。

**第二，削弱证据约束。** “品牌价值高”“工艺独特”“渠道完善”“客户认可”等表述，不能代替收入来源、成本口径、再投资和现金转换的检验。

**第三，提前混入竞争优势分析。** 品牌、资源、稀缺性、模仿壁垒等问题与后续竞争优势课程存在交叉。商业模式阶段应先解释“如何运转”，再追问“为何比别人更好、为何难以复制、能够维持多久”。

但仅保留财务指标也不够。四环节之间必须加入机制问题，否则学生只能列出数字，无法解释客户为什么付费、供给为何受约束、渠道如何改变价值归属，以及库存为何不一定等于滞销。

### 1.4 统一概念层级

课程中的商业模式先回答“怎样赚钱”，再把财务关系与经营活动接起来。这里应区分总体方式、经济逻辑与盈利模式，不把三个名称轮流用于同一段内容。

| 概念 | 课程采用的含义 | 使用边界 |
| --- | --- | --- |
| 商业模式（business model） | 企业面向哪些客户提供什么价值，依靠哪些资源、能力、活动、渠道与交易安排创造、交付并获取价值 | 总体安排不能由指标清单或管理层标签代替 |
| 商业模式的经济逻辑 | 沿收入、成本、资本投入、现金流说明企业怎样运转，以及这些关系如何形成经济结果 | 构成第一层叙事，不等于只填一张财务表 |
| 盈利模式（profit formula） | 价格、销量、产品与渠道结构、成本、税负及资本投入共同形成经营收益、现金流与资本回报的逻辑 | 是价值获取的核心，不是完整商业模式；不用“盈利机制”再建立一个并列术语 |
| 单位经济（unit economics） | 在单个产品、订单、客户等明确经营单位上，比较单位收入、相关成本及贡献 | 毛利率可作为汇总观察指标，但不能代替完整单位经济分析 |
| 资本投入 | 维持与扩大业务需要占用的长期经营资产和经营性营运资本 | 回答“业务需要多少资本”；存量、支出与增量必须区分 |
| 资本配置（capital allocation） | 管理层在再投资、现金留存、金融资产、分红、回购、并购与偿债等用途之间分配资本 | 回答“取得的资金怎样安排”；本稿作为现金流后的延伸 |
| 竞争优势 | 企业相对竞争者在价格、成本、效率、客户关系或网络等方面的有利差异，以及其持续性 | 需要跨期和可比对象证据，不由品牌或高毛利单独推出 |
| 护城河（economic moat） | 阻碍竞争者复制、替代或侵蚀竞争优势，使超额回报可能持续的机制 | 强调优势的持续性原因，不与商业模式或单期优势混用 |

课件所说的“获得收入—承担成本—配置资本”，在本稿的执行层落实为“收入—成本—资本投入—现金流”。其中“配置资本”首先要求认识经营需要的投入；专门讨论管理层怎样分配经营与融资所得资金时，采用“资本配置”。这样保留课件原意，同时避免把投入需求与资金用途混成一个计算口径。

第一层叙事说明经济结果及其联系，第二层叙事说明价值创造、交付和获取的经营安排。价值主张交代客户是谁、获得什么价值，贯穿两层。盈利模式是第二层价值获取的核心，但其变量在第一层已经开始分析。

基酒贮存所需的等待时间，通过存货、生产设施、周转周期和资本回报率（ROIC）观察。本稿用“长生产周期中的资本占用”作解释，不把时间另设为能与会计投入资本相加的科目。

### 1.5 价值问题如何嵌入财务四环节

| 财务环节 | 应追问的商业模式问题 | 对应的价值逻辑 |
| --- | --- | --- |
| 收入 | 企业向谁销售什么？客户为什么付费？销量、价格、产品与渠道如何形成收入？ | 价值主张、价值交付、价值获取 |
| 成本 | 企业为了创造和交付价值承担什么成本？哪些成本来自销量，哪些来自产能、时间、渠道和组织？ | 价值创造、价值交付、价值获取 |
| 资本投入 | 企业为维持和扩大经营系统，需要提前形成多少库存、产能和其他经营资本？ | 价值创造系统的维持与扩张 |
| 现金流 | 会计利润能否真正转化为现金？现金表现是否受到时点、金融活动或一次性项目影响？ | 价值获取的现金实现 |
| 资本配置〔延伸〕 | 再投资、留存资金和股东回报如何安排？新增投入能否获得合理回报？ | 已获取价值的再分配与再投入 |

这些关系不是一一对应：例如，直销同时影响收入、成本和现金回收；长期贮存同时影响产品供给、库存资本和未来收入。映射表的作用是连接问题，而不是再造一套独立任务清单。

### 1.6 第一层叙事为什么已经是一种叙事

先看四个问题：收入怎样形成，成本怎样发生，为维持与增长需要投入多少资本，最后有多少利润转化为现金。如果只是依次报告收入、毛利率、Capex 和 CFO，这仍是指标清单。第一层叙事要求把它们连接为一套经济逻辑。

例如，收入增长若来自销量增加，就要继续说明增加的销量需要多少生产能力、库存和渠道投入；若主要来自同规格实现价格提高，则要观察销量是否受损、单位成本是否变化，以及新增收入有多少转化为利润。利润增加之后，还要检验存货、经营性应收应付及资本支出是否吸收了相应现金。四环节之间的关系，比单个指标的高低更能说明企业如何运转。

因此，第一层叙事至少包含三条联系：收入驱动如何进入单位盈利，收入增长如何引致资本需求，利润如何经过营运资本变化与长期资产投入形成现金结果。它既包含经过核验的财务事实，也包含标明证据边界的关系解释。尚不能识别价格与结构贡献，或者尚不能完整分拆财务公司影响，并不妨碍形成阶段性叙事；这些限制本身就是叙事的一部分。

这里的“收入—成本—资本投入—现金流”是分析顺序，不是会计确认顺序。生产设施和基酒库存可能早于当期收入形成；资本性支出也不能直接作为当期费用扣减利润。叙事要沿分析问题展开，同时保留真实的生产、销售和现金回收时间差。

### 1.7 第二层叙事增加了什么解释

第一层可以说明“哪些产品与渠道形成收入、利润怎样形成、增长需要多少投入、现金如何回收”。第二层进一步追问：这些结果由什么经营活动和交易安排产生？企业创造了什么客户价值，怎样将产品交付给客户，又凭借怎样的价格、渠道和收益分配安排保留经济收益？

**价值创造**讨论资源和活动如何形成客户需要的产品或服务。茅台案例中，生产、贮存和质量控制是待核验的活动，成本、库存和生产设施是其财务表现。生产周期长既可能影响品质与供给，也可能增加库存占用；只有销售兑现与客户需求证据支持，才能说明这种投入具有经济价值。

**价值交付**讨论产品如何到达客户，以及渠道、交易和收款安排如何实现这种交付。直销与批发代理不仅是收入分类，也意味着不同的市场覆盖、渠道费用和收益归属。直销比例提高是否改善上市公司的收益，需要回到第一层的收入、成本和现金证据，而不能以渠道名称替代机制检验。

**价值获取**讨论企业从已创造并交付的价值中取得多少收入与经营收益，以及这些收益能否形成合理的资本回报和现金。客户支付的终端价格并不全部归上市公司；高毛利也不说明税费、期间费用与资本占用已经得到补偿。价值获取必须承接第一层对利润、再投资和现金转换的分析。

两层不是同一段文字的两套标题。第二层应增加“活动与资源如何产生结果”“交易安排如何改变价值归属”的机制解释。若第二层仍只是把收入改称价值获取、把成本改称价值创造，就没有完成递进。若需要的新机制证据尚未取得，就回到第一层底稿增量取证，再更新两层叙事；不能用流畅文字填补缺口。

### 1.8 概念统一的具体规则

首次出现采用中文固定名称并注明必要英文或缩写，后文沿用同一称谓。本文的具体口径如下。

| 原稿需要归并的表述 | 统一表达 | 使用说明 |
| --- | --- | --- |
| story、商业模式故事、作为成果名称的商业模式解释 | 商业模式叙事（story） | “叙事”是本稿统一中文表达；不改变叙事—变量—证据矩阵的既有名称 |
| 财务验证框架、经济逻辑 | 商业模式的经济逻辑 | 第一层叙事的固定名称；财务验证仍可作为工作动作 |
| 价值三部曲、机制组织层 | 价值创造—价值交付—价值获取 | 第二层叙事的三个专业概念，不增加并行框架 |
| 盈利机制、利润公式等 | 盈利模式（profit formula） | 沿用 Append5，说明其为价值获取核心 |
| 单位经济性、单位盈利特征等概念名称 | 单位经济（unit economics） | 分析时再注明单位毛利、单位经营贡献或其他具体口径 |
| 平均实现售价、隐含 ASP | 平均售价（ASP） | 本稿用同口径确认收入除以销量估算；与同规格价格区分 |
| 投入资本回报率、资本回报率等中文全称 | 资本回报率（ROIC） | 沿用主课件表达；术语表保留 ROIC 条目并注明其投入资本口径 |
| 资本周转效率、销售/资本比率等 | 营业收入/投入资本比率（sales-to-capital ratio） | 明确存量观察与边际估计，不把两种分母混为一谈 |
| 报表 CFO、Reported CFO | 合并 CFO | 茅台案例以合并现金流量表为起点 |
| Adjusted Industrial CFO、调整后 CFO | 调整后实体经营 CFO | 明示调整范围、带符号金额和合并抵销 |

## 二、教学方法：两层叙事的建构与证据闸门

### 2.1 第一阶段：建构商业模式的经济逻辑叙事

学生沿固定主线开展分析：

```text
收入 → 成本 → 资本投入 → 现金流
```

每个环节都应记录六类内容：已核验事实、派生计算、机制解释、替代解释、Unknown 和下一步取证。

这一阶段的成果保留 **商业模式经济逻辑图**，即“侦探底稿”。在图与底稿之外，还应写出一段沿四环节展开的经济逻辑叙事，说明指标之间的关系及其边界。没有这段连接，成果仍可能停留在数字汇总。

### 2.2 第二阶段：综合形成商业模式叙事

完成第一阶段的核验后，再按以下顺序组织解释：

```text
候选价值主张
    ↓
价值创造
    ↓
价值交付
    ↓
价值获取
    ↓
当前结论与失效条件
```

这一阶段的成果是 **商业模式叙事**，即“侦探结案陈词”。它承接第一阶段已经形成的经济逻辑叙事，进一步组织客户价值、经营活动和财务结果之间的关系。需要补充的客户、流程或渠道证据，仍登记在同一底稿中，保留第一阶段的证据编号和状态。

第一阶段主要训练年报定位、口径识别、数据计算、证据核验和替代解释；第二阶段主要训练机制整合、商业判断、叙事组织、边界表达和反证思维。

### 2.2.1 两层递进的检验方法

学生可以逐段自问：第二层的这一解释，承接了第一层哪项经济关系？增加了什么经营机制？哪些证据使这一机制比替代解释更合理？尚不能判断的部分是否仍然明确标为 Unknown？

| 第一层已经说明的问题 | 第二层应进一步解释的问题 | 所需承接证据 |
| --- | --- | --- |
| 销售收入由产品、销量、实现价格和渠道结构共同形成 | 产品为何被客户选择，生产与渠道怎样支持销售 | R01—R03、B01—B02 |
| 毛利与经营盈利受价格、单位成本、税费及期间费用影响 | 创造与交付价值的活动怎样影响成本，上市公司保留了多少收益 | C01—C02、R01—R02 |
| 业务需要库存、生产设施及其他经营资本 | 长周期生产如何安排供给，资本为什么必须提前投入 | I01—I04、B01 |
| 合并利润与 CFO 存在调整差额，再投资影响现金剩余 | 交易与收款安排怎样实现现金，价值获取是否经得起多期检验 | F01—F03、I03 |

两层共用事实与计算，但解释深度不同。第一层尚未识别的因果关系，不会因为进入第二层就自动得到解决。

### 2.3 两阶段之间的证据闸门

> 进入商业模式叙事写作阶段，不意味着证据自动升级。第一阶段的 Unknown，不能在第二阶段悄悄变成事实或确定性结论。

| 第一阶段状态 | 第二阶段允许的表达 | 约束 |
| --- | --- | --- |
| Fact：已核验事实 | “年报显示……” | 能追溯到原始文件、位置与口径 |
| Fact：基于已核验输入的派生计算 | “根据统一口径计算……” | 保留公式、输入值、单位和计算过程 |
| Interpretation：机制解释 | “一种可能解释是……” | 明示推断性质，并列出替代解释 |
| Forecast：预测 | “在……假设成立的情况下，预计……” | 列明假设、期限和敏感因素，不能用预测反证当前事实 |
| Decision：决策 | “基于以上证据与条件，作出……” | 与事实分开；商业模式解释本身不自动导出投资决策 |
| Unknown：未知事项 | “现有材料尚不能判断……” | 保留缺口和后续取证方式 |
| 未经核验的 Agent 输出 | 不得作为已证实内容进入正式 商业模式叙事 | 只能作为待核验线索 |
| 多种解释并存 | 同时写出替代解释及区分它们所需的证据 | 不因偏好某种叙事而省略其他解释 |

“派生计算”是对证据处理方式的补充说明，不必在 Fact / Interpretation / Forecast / Decision / Unknown 之外另设一套平行状态。输入本身未经核验时，算术正确也不等于事实成立。

**例：收入增长的证据转换。**

第一阶段的记录是：

> 原稿记录 2024 年营业收入增长 15.71%，但销量、ASP 和产品结构贡献尚未拆解。

第二阶段可以写：

> 公司收入继续增长，但现有证据尚不能判断增长主要来自销量、价格还是产品结构。

不能写：

> 公司凭借强大定价权实现收入增长。

后一句将未经识别的增长原因，错误地升级成了已经证实的机制。

## 四、第一阶段：沿四个环节重建经济逻辑

### 4.1 收入：企业向谁销售什么，增长从哪里来

#### 4.1.1 核心问题与候选解释

学生应回答：核心产品是什么，客户与购买理由是什么，收入通过哪些产品和渠道实现，以及增长由哪些因素驱动。

候选解释是：茅台收入主要来自核心茅台酒；收入增长可能来自销量、实现价格、产品结构和渠道结构变化，不能用总收入增长替代原因分解。2024 年基准记录 D01—D06 能说明收入来自哪里，尚不能充分说明收入为什么增长。

客户为什么愿意购买属于待解释问题。年报中的收入或毛利率不能单独证明客户动机，必要时还需补充需求、购买行为和终端价格等证据。

#### 4.1.2 基本分解关系

主课件采用“**市场需求量 × 市场份额 × 平均售价**”的收入三乘数。这一表达用于组织驱动因素；落实为可计算关系时，要把市场需求量具体化为所选边界下的市场数量口径。以下使用可取得的市场总销量与数量份额演示，避免用销售金额再乘一次价格。

平均售价（ASP）在本案例按同口径收入除以销量估算，反映公司已确认收入的平均单位水平。它可能随产品或渠道组合变化，不能直接解释为同规格提价。

同一产品、同一计量口径下：

$$
\text{收入}=\text{销量}\times\text{平均售价（ASP）}
$$

采用一致的市场边界和数量口径时：

$$
\text{公司销量}=\text{市场总销量}\times\text{公司数量份额}
$$

因此可写为：

$$
\text{收入}=\text{市场总销量}\times\text{公司数量份额}\times\text{ASP}
$$

这里的市场总销量是可观察的交易数量，不能未经说明就等同于无法直接观测的潜在需求量。公司销量与行业分母还必须统一期间、单位、统计范围和市场定义，不能用行业产量或金额指标直接替代行业销量。

对于多产品、多渠道企业，更完整的表达是：

$$
R_t=\sum_i\sum_c Q_{i,c,t}\times P_{i,c,t}
$$

其中，$i$ 表示产品，$c$ 表示渠道，$Q$ 为同口径销售数量，$P$ 为同口径单位实现价格。

研究时可将收入变化分析为数量、同规格价格、产品组合和渠道组合的影响，但这些因素存在交互。没有选定明确分解方法前，不能将四项机械相加并当作严格恒等式；数据不足时应保留交互项或未解释项，避免重复归因。

#### 4.1.3 收入机制检验表

| 候选机制 | 应观察的数据 | 支持机制的表现 | 替代解释或削弱证据 |
| --- | --- | --- | --- |
| 销量增长 | 茅台酒、系列酒销量；对应库存与产能 | 销量增长具有持续性，并有供给能力支持 | 收入增长但销量停滞或下降，说明增长不能归因于销量 |
| 价格提升 | 同规格实现价格；产品收入÷同口径销量 | 同规格价格提高，销量与相关市场份额未持续受损 | 平均售价（ASP） 上升主要来自高价产品占比变化 |
| 产品结构升级 | 各产品收入、销量、吨价与单位利润 | 高价产品占比提升，并改善单位盈利 | 仅为披露分类调整，或低价产品收缩造成的占比变化 |
| 渠道价值回收 | 直销与批发收入、成本、毛利率、销售费用 | 直销占比提高，同时净经营贡献和现金回收改善 | 销售费用、平台费用或其他新增成本抵消渠道收益 |
| 市场份额提升 | 公司销量及同边界行业销量 | 在同一市场定义下，公司销量增长持续快于行业 | 只是行业整体扩张，或统计范围发生变化 |

这些证据首先用于识别增长机制。某项证据不支持“价格驱动”，并不等于推翻公司全部商业模式。

#### 4.1.4 收入数据缺口

优先补齐 2020—2024 年茅台酒、系列酒收入与销量，再向 2015 年回溯，计算同口径平均售价（ASP）；同步整理直销与批发代理的多年收入、成本、毛利率及相关费用。

价格证据应区分同规格飞天茅台的出厂价、批发价和终端价。上市公司的确认收入不等于终端成交金额，不能将终端价差直接视为上市公司可获得利润。

市场份额方面，应分别处理全部白酒与高端白酒市场，明确数量份额和金额份额的区别。原稿所述现有行业销量仅到 2019 年，2020 年后的同口径销量存在缺口，**不得用其他行业金额指标拼接分母，也不得靠估算制造连续序列**。

#### 4.1.5 阶段结论

> 已知核心产品和渠道结构，但收入增长来源尚未完全拆解。“定价权驱动增长”仍是待检验假设。

### 4.2 成本：创造和交付价值需要付出什么

#### 4.2.1 成本不能只看营业成本

成本分析至少覆盖五个方面：

```text
原料与生产
    ↓
长周期贮存及相关资本占用
    ↓
税金及附加
    ↓
渠道与市场投入
    ↓
管理、研发与组织运营
```

这是一张经济问题清单，不是五项可以直接相加的利润表科目。贮存等支出可能按适用会计处理进入存货成本或期间费用，分析时应追踪原始列报，避免重复扣减。

#### 4.2.2 从收入到经营盈利的分析桥

原稿指向 2024 年报附注 40，记录了茅台酒、其他系列酒及其他业务的收入和成本，并计算商品类型综合毛利率约 91.93%。

但高毛利可能反映不同机制：较高实现价格、较低直接生产成本、既有产品与品牌结构，或者重要经济成本列在营业成本之外。渠道端利润也不全部出现在上市公司的营业成本中。

可先构造以下分析桥：

```text
营业收入
− 营业成本
= 毛利

− 税金及附加
− 销售费用
− 管理费用
− 研发费用
= 经营利润小计〔分析口径〕
```

上述小计 **不直接等于报表营业利润**。还需按报表逐项衔接财务费用、其他收益、投资收益、公允价值变动、减值及资产处置等适用项目，明确哪些属于实体白酒经营、哪些不属于。

#### 4.2.3 用吨价与吨成本区分价格和生产成本

$$
\text{吨价}=\frac{\text{产品收入}}{\text{同口径产品销售量}}
$$

$$
\text{吨成本}=\frac{\text{产品营业成本}}{\text{同口径产品销售量}}
$$

$$
\text{单位毛利}=\text{吨价}-\text{吨成本}
$$

收入、营业成本与销量必须对应同一产品分类和期间。组合层面的吨价上升不等于同规格提价，单位毛利也不等于已经扣除税费、渠道费用和资本成本的扣除资本成本后的单位利润。

#### 4.2.3.1 从单位毛利到单位经济

单位经济先选经营单位，再比较相应收入与成本。茅台案例可以在披露允许时按一吨同口径产品观察。吨价减吨成本得到单位毛利；继续纳入相应单位税负、渠道费用与其他相关成本，才逐步接近盈利模式的单位经营贡献。

沿用 Append5 的简化表达：

$$
\text{单位经营贡献}=\text{单位实现价格}-\text{单位生产成本}-\text{单位税负与渠道费用}
$$

这里必须保留两个限制。第一，单位生产成本若使用“吨成本”代替，应说明它是已销售产品营业成本口径，而不是当年基酒生产现金投入。第二，该小计尚未自动扣除全部组织费用和资本成本，不等于单位净利润或完整经济利润。没有可靠分摊资料时，只计算可支持的小计，把其余部分保留为 Unknown。

> *投资启示：高毛利说明每单位收入在营业成本之后留下较多收益；单位经济继续追问，为取得这笔收入还付出了哪些税费、渠道与组织成本，以及占用了多少资本。*

#### 4.2.4 长生产周期如何进入成本与资本分析

原稿提出的经营流程是：

```text
采购原料 → 制曲 → 制酒 → 贮存 → 勾兑 → 包装 → 销售
```

流程、各阶段年限及成本转结方式仍应回到原始披露核验。其分析意义在于：生产投入与最终销售之间可能存在明显时间差。

这一时间差可能体现为在产品和自制半成品库存、较长周转周期、对历史基酒的依赖，以及较大的经营资本占用。因此，企业可能同时具有高毛利、低应收占用、较高库存时间占用和较低短期供给弹性。

由此不能直接推断“轻资产”。更准确的待检验问题是：固定资产、库存资本和投入到回收的等待周期，分别占用了多少资源，产生了多大回报？

#### 4.2.4.1 成本结构：经营杠杆、规模经济与资本密集度

主课件把成本结构落实为固定成本与变动成本，并由此追问经营杠杆。收入增加时，相对固定的厂房、组织与经营费用是否被摊薄；收入下降时，它们能否相应收缩？这些问题要看业务量变化怎样传导到经营利润，不能只用某一年费用率低判断成本优势。

规模经济与资本密集度也不是同一件事。前者问规模扩大是否降低单位成本或摊薄相对固定费用，后者问维持和扩大收入需要占用多少长期资产与营运资本。茅台可能同时有较高毛利、较低应收占用以及较大的基酒库存占用；这些特征必须分开检验。

| 可核验问题 | 证据要求：变量／方向／时点／口径 | 反证条件 |
| --- | --- | --- |
| 收入变化是否通过固定成本摊薄影响经营利润 | 多期收入、单位成本与经营利润；分开价格、结构、一次性项目和相对固定费用 | 利润弹性主要由提价或一次性项目形成，不能归因于固定成本摊薄 |
| 规模扩大是否改善单位经济 | 同产品单位收入与成本、销售管理费用率；按可比期间观察必要投入与服务能力 | 费用下降来自减少必要投入，或收入扩大仍未改善成本与贡献 |
| 高毛利是否伴随低资本投入需求 | Capex、固定资产、在建工程、存货及营业收入/投入资本比率；按成熟期匹配 | 库存和资本占用持续增长，后续销售及回报没有兑现 |

> *投资启示：成本能否被规模摊薄，与增长需要多少资本是两个问题。高毛利不能独立证明规模经济，也不能独立证明轻资产。*

#### 4.2.5 成本数据缺口

| 数据组 | 需要补充的内容 | 主要用途 |
| --- | --- | --- |
| 单位收入与单位成本 | 连续 5—10 年茅台酒和系列酒的吨价、吨成本；原材料、人工与制造费用的单位拆分 | 识别高毛利来自价格还是成本 |
| 税费与渠道 | 消费税及附加占收入比例；销售费用与直销扩张的对应关系 | 判断毛利能否转化为净经营贡献 |
| 库存与成本结转 | 原材料、在产品、自制半成品和库存商品结构；不同年份基酒如何结转销售成本 | 连接生产周期、库存和当期盈利 |
| 渠道外部收益 | 经销商毛利、终端价差及渠道库存 | 区分上市公司价值获取与渠道端收益 |
| 同业比较 | 与五粮液、泸州老窖等公司同口径的吨价、吨成本、税费和费用率 | 判断相对差异，避免会计与产品组合造成误判 |

#### 4.2.6 阶段结论

> 已知茅台具有高毛利，但高毛利的具体来源尚未完全识别。需要进一步区分价格、单位成本、产品组合、税费和渠道机制，才能讨论其持续性。

### 4.3 资本投入：维持和扩大业务需要多少资本

#### 4.3.1 不能把再投资等同于当年 Capex

原稿记录，2024 年购建固定资产、无形资产和其他长期资产支付的现金为 46.79 亿元，同比增加 78.59%。这只是一项现金流量表数据，不能替代完整的经营再投资分析。

在明确经营范围、资本支出及折旧摊销口径后，可使用以下简化关系：

$$
\text{再投资}=\text{净资本支出}+\Delta\text{非现金营运资本}
$$

$$
\text{净资本支出}=\text{经营性资本支出}-\text{对应经营资产的折旧与摊销}
$$

这里的再投资是用于分析经营资本增量的口径，不是又一项可以直接与 CFO 并列相加减的报表项目。资产处置、并购、非现金新增和重分类等影响应另行核对。

#### 4.3.2 非现金营运资本的经营口径

茅台不能机械套用一般制造业公式。应从经营性流动资产与经营性无息流动负债出发，至少审视：

```text
存货
+ 应收账款
+ 应收票据
+ 预付款项
+ 其他明确属于实体经营的非现金流动资产
− 应付账款
− 合同负债
− 其他明确属于实体经营的无息流动负债
= 非现金营运资本〔分析口径〕
```

应剔除或单列现金及有价证券、付息债务、财务公司特有金融资产与金融负债，以及不属于实体白酒经营的资金归集项目。其他经营资产负债是否纳入，需逐项说明，不能因名称含“其他”就全部归入或全部剔除。

合同负债和经营性应付款可能减少资金占用，但其可持续性仍需检验，不能只看到某年余额上升就认定融资优势稳定存在。

#### 4.3.3 关键机制：提前形成基酒库存

若第 $t$ 年销售的部分产品依赖第 $t-k$ 年形成的基酒，则当期收入不仅依赖当期 Capex，还依赖历史产量、库存积累、产能投产时间、成熟周期以及可用于勾兑的质量和数量。

应建立“生产—库存—销售滞后表”：

| 年份 | 基酒产量 | 产品销售量 | 存货及结构 | 在建工程 | 固定资产 | 经营性 Capex | 后续年份销售表现 | 口径与证据 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| $t$ | 待填 | 待填 | 待填 | 待填 | 待填 | 待填 | 观察 $t+k$ 年 | 标明原始出处及推断限制 |

不同年份和产品的 $k$ 不应预先设为同一固定值；基酒产量与成品酒销量也未必可以一比一对应。应先核验生产、贮存、勾兑及计量关系，再研究滞后联系。

核心检验问题是：

> 今天的销售增长，主要依赖当期新增投入，还是多年前形成的基酒与产能在本期释放？

如果后者更重要，则当期 Capex／收入较低不代表增长不需要资本，库存也不必然等于滞销。但库存未来能否按预期价格兑现，仍取决于需求和销售证据，不能把全部库存直接当作未来高价收入。

#### 4.3.4 资本效率与增量回报

首先统一利润与资本范围。分析实体白酒经营时，应使用同一经营范围的税后经营利润（NOPAT）与投入资本，不能用合并利润搭配剔除了财务公司的资本。

NOPAT 可由调整后的经营利润扣除相应经营税负估算；采用“经营利润 ×（1 − 税率）”时，应说明税率假设及适用限制。投入资本可从经营性资产扣除经营性无息负债构造，平均值通常使用期初、期末余额，但明显季节性或阶段性投入需要更细处理。

$$
\text{营业收入/投入资本比率}=\frac{\text{营业收入}}{\text{平均投入资本}}
$$

$$
\text{再投资率}=\frac{\text{净资本支出}+\Delta\text{非现金营运资本}}{\text{NOPAT}}
$$

$$
\text{ROIC}=\frac{\text{NOPAT}}{\text{平均投入资本}}
$$

主课件的“营业收入/投入资本比率”用来判断资本投入强度。本稿上式采用平均投入资本观察存量经营效率；用于估计未来增长需要多少再投资时，则关注同一成熟周期内的收入增量与相应再投资。

$$
\text{再投资额}\approx\frac{\text{营业收入增量}}{\text{边际营业收入/投入资本比率}}
$$

边际比率不是“营业收入÷平均投入资本”的自动替代值。茅台的生产与销售存在滞后，需说明投入期间、成熟期及后续销售窗口。课件的“增长率≈再投资率×资本回报率（ROIC）”也有稳定回报等条件，主要连接税后经营利润增长与资本投入；不能未经说明当成收入增长的严格恒等式。

增量指标可作为进一步检验工具：

$$
\text{边际营业收入/投入资本比率}=\frac{\Delta\text{营业收入}}{\text{相应期间再投资}}
$$

$$
\text{增量资本回报率（分析口径）}=\frac{\Delta\text{NOPAT}}{\Delta\text{投入资本}}
$$

这些指标不能机械使用同年分子、分母解释长周期投入的效果。应检查多年累计或合理滞后关系，并核对投入资本变化与再投资之间的勾稽；分母接近零或为负时，应单独解释，避免把异常比率误读为经营效率。

重点不在某一年 ROIC 多高，而在新增投入是否形成后续收入和 NOPAT、新产能能否成为可销售资源、边际回报是否下降，以及库存是否超过需求消化能力。

#### 4.3.5 资本投入数据缺口

| 数据组 | 需要补充的内容 |
| --- | --- |
| 资本支出 | 维持性与扩张性 Capex；项目性质；现金支付与实际建设进度 |
| 产能建设 | 在建工程项目、预算、完工进度、预计投产时间；设计产能与实际产量 |
| 基酒库存 | 存货分类、可取得的库龄信息、生产至销售滞后、可销售资源形成过程 |
| 经营融资 | 合同负债、应付账款和其他经营负债的准确经营属性 |
| 合并范围 | 财务公司资产负债及资金归集对投入资本的影响 |
| 长期回报 | 连续 5—10 年 NOPAT、投入资本、再投资率、ROIC，以及新增投入与后续收入的对应关系 |

#### 4.3.6 阶段结论

> 茅台固定资产相关投入相对于利润可能不高，但基酒库存和投入到销售之间的时间差是重要的资本约束。其实际资本轻重与增量效率，需要长期、同口径数据验证。

### 4.4 现金流：利润能否真正转化为现金

#### 4.4.1 2024 年截面说明了什么

按原稿记录，2024 年合并净利润为 893.35 亿元，CFO 为 924.64 亿元，CFO／净利润为 103.50%，差额约 31.29 亿元。存货增加产生约 79.08 亿元负向调整，经营性应收减少和应付增加分别产生约 17.61 亿元与 80.66 亿元正向调整。

这说明该年度合并口径利润总体转化为经营现金，但不能直接得出长期现金流质量很高，因为还需要区分营运资本波动，以及合并范围内财务公司的客户存款、贷款、同业和资金归集活动。

#### 4.4.2 同时保留报表 CFO 与调整后实体经营 CFO

**报表口径：**

$$
\text{合并 CFO}=\text{合并现金流量表列示的经营活动现金流量净额}
$$

**实体经营分析口径：**

$$
\text{调整后实体经营 CFO}
=\text{合并 CFO}
-\text{财务公司特有活动对合并 CFO 的净贡献}
+\text{其他有证据支持的调整}
$$

“净贡献”按带符号金额处理，且应考虑合并抵销。不能简单扣除财务公司单体现金流，或将所有金融相关科目一律剔除。披露不足时，应保留不可拆分项目、给出边界，而不是制造一个貌似精确的调整值。

随后分别比较：

$$
\frac{\text{合并 CFO}}{\text{合并净利润}}
$$

$$
\frac{\text{调整后实体经营 CFO}}{\text{同范围的实体经营利润}}
$$

第二个比率必须进一步说明分母采用净利润还是其他经营利润指标，以及税费、利息和合并范围的处理。不同口径的比率不能不加说明地横向比较。

#### 4.4.3 自由现金流必须标明口径

首先可建立经营现金剩余的代理指标：

$$
\text{自由现金流代理指标}=\text{调整后实体经营 CFO}-\text{同口径经营性 Capex}
$$

代理指标并不自动等于企业自由现金流（FCFF）或股权自由现金流（FCFE）。原稿中的 877.85 亿元只是“924.64 − 46.79”的算术观察值，尚未完成实体经营调整、资本支出分类及资金权属口径核验。

若采用以 NOPAT 为起点的简化 FCFF 框架，则为：

$$
\text{FCFF}=\text{NOPAT}+\text{折旧与摊销}-\text{经营性 Capex}-\Delta\text{非现金营运资本}
$$

各项须为同一经营范围，并视情况处理其他经营性非现金项目。FCFE 还需统一利息、债务融资及股东可得现金口径，不能直接沿用上述代理值。

**关键区别：** 从 NOPAT 出发需要处理营运资本增加；从已经包含营运资本变动的 CFO 出发，不能再扣一次同样的营运资本增加。

#### 4.4.4 如何判断现金转换质量

应检查连续 5—10 年的 CFO／利润、FCF／利润、营运资本贡献和财务公司影响，分辨经营能力与年度时点波动。

不能把“每年 FCF 都必须超过净利润”作为好商业模式的必要条件。扩张投入会影响当期 FCF；重要的是现金转换、必要再投资和后续资本回报之间能否形成可解释、可持续的关系。

#### 4.4.5 现金转换数据缺口

| 数据组 | 需要补充的内容 |
| --- | --- |
| 长期现金转换 | 连续 5—10 年 CFO／利润和同口径 FCF／利润 |
| 营运资本桥 | 存货、合同负债、经营性应收应付及其他调整项目的年度贡献 |
| 财务公司调整 | 对合并 CFO 的年度净影响、内部抵销及不能拆分的部分 |
| 资本支出分类 | 经营性 Capex、金融投资现金流和其他投资活动的区分 |
| 现金归属与用途 | 现金所在主体、受限情况、分红及其对余额和资本结构的影响 |

#### 4.4.6 阶段结论

> 2024 年原稿记录显示较强的合并现金转换，但其结果受到营运资本和财务公司活动影响。尚需多期、同口径的实体经营现金流序列，才能判断长期现金创造能力。

## 五、延伸分析：经营现金的资本配置

### 5.1 为什么保留资本配置，但不改变四环节主线

“业务需要多少资本”与“赚到的钱如何分配”是不同问题。前者属于资本投入，后者属于资本配置。

资本配置应保留在案例分析中，作为现金流环节的延伸和综合结论的反馈，而不是取代 Lec03 既有章节、另增一条平行教学主线。

从经营资金安排的角度，应观察维持产能、扩张产能、形成基酒库存、技术与渠道投入、现金储备、金融资产、其他投资和分红。但这些用途分布在不同报表项目中：库存变动通常已进入 CFO，费用化的渠道投入也已影响利润和现金，不能在现金去向表中再扣一次。

### 5.2 资本配置候选命题

> 核心经营产生的现金可能超过当期长期资产购建需求，但业务扩张仍需提前形成基酒库存和生产能力。必要再投资之后的资金用于分红、现金留存或其他投资。配置是否合理，取决于新增经营投入的回报、留存现金的用途及资金约束，而不只取决于分红比例高低。

这仍是待检验命题。不能仅凭某年较低的 Capex／CFO，认定所有剩余资金都可以无条件分配。

### 5.3 先做现金勾稽，再解释用途

合并报表的基本现金勾稽应为：

$$
\Delta\text{现金及现金等价物}
=\text{CFO}+\text{CFI}+\text{CFF}+\text{汇率变动影响}
$$

其中，CFI 为投资活动现金流量净额，CFF 为筹资活动现金流量净额。进一步按原始现金流项目拆解经营性资本支出、资产处置、对外投资、融资、利息与股利等用途，并保持完整勾稽。

需要遵守三个口径边界：

1. **不得重复扣减营运资本。** CFO 已反映相关经营现金变动；“CFO − Capex − 营运资本增加”会在通常的同口径情形下重复扣减。
2. **不要混用实体经营与合并现金。** 使用调整后实体经营 CFO 分析资金分配时，若要回到合并现金余额，需要将此前剔除的其他活动接回。
3. **现金及现金等价物不自动等于货币资金。** 应核对受限资金、现金等价物范围及其他口径差异。

### 5.4 资本配置观察指标

| 指标或问题 | 主要观察内容 | 使用提醒 |
| --- | --- | --- |
| 分红／净利润 | 利润分配力度 | 明确归属年度、归母或合并口径，以及普通与特别分红 |
| 实际现金分红／同口径 FCF | 现金分配与经营现金剩余的关系 | 区分拟分红、已宣告分红和当期实际支付金额 |
| 现金及金融资产／总资产 | 资金留存与资产结构 | 关注所在主体、用途和可支配性，不默认全部可供上市公司股东使用 |
| 经营性 Capex／CFO | 当期经营现金用于长期资产的程度 | 不能据此忽略库存投入或项目支付节奏 |
| 再投资率与增量资本回报率 | 留存资金是否创造新的经营回报 | 结合生产和销售滞后观察 |
| 新增产能投产及收益 | 建设投入是否转化为有效供给与盈利 | 区分设计能力、实际产出、成熟基酒与最终销量 |

资本配置结论应回答：哪些投入是在维持既有经营，哪些在支持增长，哪些资金暂未投入，以及股东回报是否与再投资机会相匹配。

| 长周期供给具有经济价值 | B01、I02、R01、R03：历史产量、库存、未来销量和价格 | 库存积累来自需求不足，而非有价值的供给储备 | 存货增加后，未来销售和实现价格未兑现，出现持续消化压力 |
| 较高资本回报能够延续 | I04：历史和增量资本回报率 | 历史资产账面成本低、一次性提价、项目投产时点 | 新增投入在合理成熟期后仍持续低回报，整体回报依赖旧资产 |

反证条件应针对具体命题使用。某项机制被削弱，不代表所有经营机制同时失效；反之，某个指标好看，也不能让其他待检验命题自动通过。

### 6.3 从相关性到机制判断

每项机制解释都应经过同一检查：观察到的结果是什么，可能原因有哪些，需要什么证据区分它们，以及什么结果会使当前解释失效。

例如，“直销占比上升”和“毛利率上升”同时出现，只能构成进一步调查的线索。还应控制产品组合、确认收入方式、税费和平台费用等变化，才能评估渠道调整的净贡献。

这正是侦探工作的核心：**每个结论有证据，每个证据有边界，每个解释有替代方案，每份商业模式叙事 都有可能推翻它的事实。**

## 七、第二阶段：从财务证据组织商业模式叙事

### 7.0 先带入第一层叙事，再形成第二层叙事

进入本节前，学生应先提交自己的经济逻辑叙事。基于原稿记录，一个保持证据边界的阶段性示范可以写成：

> **收入。** 2024 年原稿记录表明，公司收入主要来自茅台酒，批发代理与直销共同构成渠道收入。营业收入增长已经观察到，但销量、同规格实现价格、产品结构和渠道结构各自的贡献尚未充分拆解。
>
> **成本。** 原稿记录了较高的商品类型毛利率；要说明利润如何形成，还需分解吨价、吨成本、税金及附加和期间费用，不能仅由高毛利推定生产成本低或定价权强。
>
> **资本投入。** 公司不仅需要长期生产设施，也需要提前形成基酒库存。单年长期资产购建现金支出不能完整代表再投资需求，增长与资本投入之间还需要按生产成熟期考察。
>
> **现金流。** 原稿记录的合并 CFO 接近并超过合并净利润，但现金转换受营运资本和财务公司活动影响。以 CFO 减长期资产购建现金支出得到的差额，只是未经完整调整的观察值，尚不能作为已核验的自由现金流结论。

这段文字已经建立了第一层关系：收入与盈利需要进一步分解，盈利背后存在提前投入，现金结果又受到营运资本和合并范围影响。第二层应在此基础上说明：生产与贮存怎样形成供给，批发与直销怎样完成交付，价格、渠道与成本怎样影响价值获取。以下保留原稿的综合示范，并使其承接上述第一层叙事。

### 7.1 先提出候选价值主张

商业模式叙事的开头应交代三个问题：企业面向谁、提供什么价值、客户为什么愿意付费。

茅台案例可先将产品品质、市场认知和特定购买需求作为待检验方向，但不能仅凭品牌知名度、高价格或高毛利就判定客户价值已被证实。年报提供的经营和财务证据，应与可取得的需求、交易和客户行为证据互相印证。

当客户动机证据不足时，应明确写成：

> 公司通过特定产品和渠道形成收入；但客户愿意支付溢价的具体原因，以及各类需求的相对贡献，仍需进一步验证。

### 7.2 用价值创造—价值交付—价值获取建构第二层叙事

| 模块 | 应组织的机制解释 | 来自经济逻辑底稿的证据 | 必须保留的边界 |
| --- | --- | --- | --- |
| 价值创造 | 原料、制曲、制酒、贮存、勾兑和质量控制如何形成产品供给；时间如何影响库存与产能 | B01、C01、I01、I02、R01 | 长周期不自动等于有价值的稀缺，也不自动构成护城河 |
| 价值交付 | 批发代理、直销和数字化平台如何触达市场；渠道调整如何改变收入、费用与现金回收 | R02、R03、C02、F01 | 数字化平台可能属于直销，不能未经核对就列为与直销并列、互斥的收入类别 |
| 价值获取 | 销量、实现价格、产品与渠道结构如何形成利润，再经过资本占用与现金转换形成经营收益 | R01、C01、C02、I03、I04、F01—F03、A01 | 高毛利不等于高自由现金流，资本回报不等于股东投资收益 |

第二层叙事描述的是经营机制。ROIC 用来衡量资本回报，不是现金流指标；分红属于价值实现后的配置，也不能替代对经营本身的检验。

### 7.2.1 盈利模式怎样承接第一层叙事

Append5 明确：**盈利模式（profit formula）是价值获取的核心，但不是完整商业模式。** 第一层已经分析了价格、销量、产品与渠道结构、成本、税负和再投资。第二层用这些变量说明企业从客户支付中保留多少收益，并解释取得这些收益的经营安排。

例如，直销改变的可能是公司确认收入与渠道价值的归属，同时也可能增加履约和销售费用。只有收入、相关成本和现金回收能够一起比较，才能判断价值获取是否改善。又如，长周期生产可能影响产品品质与供给，但必须承担存货与设施占用；高单位毛利只有在必要投入、销售兑现和现金回收之后，才可能形成合理资本回报。

第二层因此要同时交代“价值为什么被客户认可”“价值怎样送达客户”“收益由谁取得”。它增加的是活动与交易安排的解释，而不是把毛利改名为价值获取。财报证据不足以证明文化认同或购买动机时，保留候选价值主张，不用品牌形容词代替需求证据。

> *投资启示：能够创造客户价值，不意味着上市公司能够保留全部价值；能够形成会计利润，也不意味着已经取得相应现金与资本回报。*

### 7.3 茅台统一商业模式叙事：带证据边界的示范稿

以下是综合写作示范，而非已经结案的研究结论。括号中的证据编号指向建议底稿目录；编号出现不代表证据已经齐备。

#### 第一段：候选价值主张与价值创造

> **〔Interpretation；客户动机与部分流程参数仍为 Unknown〕** 贵州茅台的候选经营机制，是通过原料采购、制曲、制酒、长期贮存、勾兑和质量控制，将原料、生产能力与等待时间转化为具有特定品质和市场认知的酒类产品。客户是否持续认可这种价值，应由同规格交易价格、销量、相关市场份额及可取得的购买行为证据检验，而不能仅由品牌叙事推定。长周期生产可能约束短期供给，但同时也要求提前形成库存和产能；这种约束是否形成经济价值，还要看产品最终能否销售兑现。

**证据连接：** B01、B02、R03、I01、I02。现有材料尚不足以完整确认客户动机、周期参数与供给约束的经济效果。

#### 第二段：价值交付

> **〔原稿记录的结构信息＋Interpretation〕** 公司通过批发代理和直销实现产品交付，数字化平台应按实际披露归入相应渠道。不同渠道可能承担不同的市场覆盖和交易功能；直销可能让上市公司获取更多渠道环节的收益，但其净效果必须结合渠道收入、成本、销售费用和现金回收检验，不能只用直销占比上升作结论。

**证据连接：** D05—D06、R02、R03、C02、F01。渠道占比只能说明结构，尚不能单独证明渠道价值回收。

#### 第三段：价值获取——收入与单位盈利

> **〔原稿记录的 Fact／派生计算＋Unknown〕** 原稿记录，2024 年茅台酒约贡献 85.39% 的合并营业收入，公司营业收入较年报中的上年比较列增长 15.71%，表明核心产品对收入具有重要影响。但现有单年材料尚不能充分区分销量、同规格价格、产品组合和渠道变化各自的贡献，因此“定价权驱动增长”仍是待检验解释。高毛利同样需要通过吨价、吨成本、税金及附加、渠道和组织费用拆解，才能判断其来源及能否持续转化为经营盈利。

**证据连接：** D01—D07、R01—R03、C01—C02。正式使用前须补齐原始出处及收入分解。

#### 第四段：承接价值创造——资本投入与时间差

> **〔Interpretation；资本轻重和增量效率仍待验证〕** 茅台的价值创造可能具有明显的时间属性：生产投入、基酒贮存和最终销售之间存在较长间隔。因此，维持和扩大业务不仅需要厂房、设备和在建产能，还需要提前形成基酒库存。2024 年原稿记录的长期资产购建现金支出为 46.79 亿元，同比增加 78.59%，但这既不能说明全部再投资需求，也不能区分维持性与扩张性投入。公司是否表现为固定资产投入相对有限、库存和时间占用较重，需要通过历史产量、存货、Capex、营运资本与后续收入之间的长期关系验证。

**证据连接：** D08—D09、B01、I01—I04。需补产能、库存与销售的滞后证据，不宜直接贴上“轻资产”标签。

#### 第五段：承接价值获取——现金实现与资本配置

> **〔原稿记录的 Fact／派生计算＋Unknown〕** 原稿记录，2024 年合并 CFO 为 924.64 亿元，约为合并净利润的 103.50%，但这一结果同时受到存货、经营性应收应付及财务公司活动影响。只有建立多期、同范围的实体经营调整序列，才能判断核心白酒业务是否稳定将利润转化为现金。经营现金在必要长期资产投入、其他投资、资金留存和分红之间的分配，还应与已经反映在 CFO 中的库存投入一并分析，避免重复扣减。现金是否属于可自由支配资金，也需要核验所在主体和使用限制。

**证据连接：** D10—D17、I03、F01—F03、A01。877.85 亿元的简单差额尚不能直接命名为 FCFF 或 FCFE。

#### 第六段：条件性综合结论

> **〔条件性 Interpretation，不是已证实的最终结论〕** 如果长期证据表明，公司能够维持客户认可和相关市场地位，实现价格或产品结构改善能够转化为净经营收益，高毛利不依赖削减必要投入，新增增长所需资本与后续回报相匹配，调整后现金转换稳定，且新增投资在合理成熟期后仍保持较好回报，那么财务数据才支持这样的商业模式解释：贵州茅台通过长周期生产形成产品供给，通过产品与渠道结构实现收入，并以较强的单位盈利能力和资本效率，将客户价值转化为经营现金及可分配收益。

**证据连接：** B02、R01—R03、C01—C02、I01—I04、F01—F03、A01。该结论还不等于已证明护城河，更不直接等于股票具有投资吸引力。

### 7.4 商业模式叙事的失效与修订条件

当前解释应在以下情况出现时被重新审视：收入增长主要由分类变化造成，而不是实际销售或净收益改善；库存和资本投入在合理滞后后仍不能转化为销售；增量资本回报持续下降；调整后现金转换明显弱于报表表现；或者客户需求与实现价格不能支撑原有供给价值判断。

修订时应明确是哪一个机制失效。例如，直销未改善利润，需要修改“渠道价值回收”的解释；新增库存不能销售兑现，需要修改“供给储备具有经济价值”的解释。不能笼统地把所有变化归结为“品牌变差”或“护城河消失”。

## 九、Lec03 的课程安排与后续衔接

### 9.1 开头：用总问题建立完整概念

可用约 5—10 分钟提出总问题：

> 企业为谁创造什么价值，通过什么经营系统交付，又如何把这种价值转化为利润和现金？

这一部分用于建立商业模式的整体视角，不扩展为另一套并行作业主线，也不在入口阶段提前讲完品牌、资源、护城河和估值。

### 9.2 主体：保留原章节骨架

| 既有章节 | 主要教学任务 | 对应成果 |
| --- | --- | --- |
| 3.1 收入来源与收入驱动因素 | 产品、客户、价格、销量、产品结构和渠道结构 | 收入底稿 |
| 3.2 成本结构与成本驱动因素 | 吨价、吨成本、税费、渠道和组织成本 | 成本底稿 |
| 3.3 资本投入与再投资 | Capex、库存、营运资本、时间差与资本效率 | 资本投入底稿 |
| 3.4 利润与现金流转换 | CFO 调节、财务公司影响、FCF；延伸至资本配置 | 现金流底稿与资金用途分析 |
| 3.5 竞争优势与模仿壁垒 | 哪些机制具有相对优势，为什么难以复制、能持续多久 | 对阶段性商业模式叙事进一步检验 |

完成 3.1—3.4 后，先形成经济逻辑图，再组织阶段性商业模式叙事；进入 3.5 时，追问哪些已经识别的经营机制可能构成竞争优势。这样既保留原章节结构，也避免在机制尚未还原前直接用“护城河”解释所有结果。

### 9.3 最后综合：从指标回到机制

课程收束时，将分析过程压缩为：

```text
客户价值假设
    ↓
收入证据
    ↓
成本证据
    ↓
资本投入证据
    ↓
现金流证据
    ↓
价值创造—价值交付—价值获取
    ↓
当前结论、替代解释与失效条件
```

学生经历的认知升级是：看见数字 → 理解关系 → 解释机制 → 建构商业模式，而不是直接接受一个现成的茅台故事。

### 9.3.1 用课件既有表达检查两层成果

| 课件固定表达 | 第一层叙事的检查 | 第二层叙事的检查 |
| --- | --- | --- |
| 可核验问题 | 收入、成本、资本投入和现金的问题是否具体 | 创造、交付与获取价值的问题是否承接前一层 |
| 证据要求：变量／方向／时点／口径 | 是否记录对应数值、期间、分母和经营范围 | 活动或交易安排是否留下可观察痕迹 |
| 反证条件 | 什么数据会削弱当前关系解释 | 什么结果会使价值主张、渠道效果或供给价值需要修订 |
| 投资启示 | 从关系中提炼可检验原则，不直接作买卖选择 | 把原则落实为变量和后续财务检验，不用形容词证明优势 |

> *投资启示：第一层让经营结果之间的关系变得清楚，第二层让产生这些结果的安排变得可解释。两层都只形成有证据边界的阶段判断，下一步仍需竞争与财务证据检验。*

```text
如何形成财务预测？
    ↓
市场价格隐含什么预期？
    ↓
估值与投资命题是否成立？
```

课程的核心分工保持不变：年报是一手证据；Agent 负责定位、整理和提出线索；学生负责核验、口径选择与判断；Fact / Interpretation / Forecast / Decision / Unknown 全程使用；每项结论可追溯，每份商业模式叙事 有失效条件。

### 10.1.1 前四次任务跑通的是最小原型

Append5 第六节强调：前四次任务不负责一次性收齐商业模式全部证据，而是在“一家公司、一份或少量年报、一个或少量指标”上，人工全量复核，保留失败、修正与停止原因。

最小原型回答的是：定位是否准确，提取字段是否稳定，口径是否能够裁决，变化是否能够复算。流程跑通，只说明值得在新年度、新指标上继续测试；它还没有证明收入增长来自定价权，也没有证明高毛利、低再投资或高现金转换能够持续。

因此，多期数据扩展不是把单次任务放大后直接相信输出。先查看前序错误记录，再把已经发现的表头、跨页、单位、主体与可比性问题纳入重复流程。若原型本身尚未稳定，应先修正原型，再扩大处理规模。

### 10.1.2 从原型到项目级 Skill

沿用 Append1、Append2 和 Append5 的顺序：**任务合同样本—多轮执行与人工纠错—稳定字段、步骤、停止条件和验收—项目级 Skill—批量证据候选—人工审计—证据库。**

| 阶段 | 可以交给 Agent 的辅助工作 | 人继续承担的责任 |
| --- | --- | --- |
| 候选生成 | 在限定原始材料中读取、定位、整理、提取线索与发现遗漏 | 定义问题、限定材料，回到 PDF 人工核验 |
| 重复测试 | 在新年度、新指标中执行相同流程，汇报候选及异常 | 记录错误，裁决期间、单位、主体与定义，修正规则 |
| 信任建立 | 稳定生成可逐行审计的字段、公式代入与缺口 | 复核例外、冲突、关键字段与高影响主张 |
| Skill 固化 | 按稳定输入输出与停止条件执行辅助步骤 | 确认适用范围，保留材料边界、核验与判断责任 |
| 批量取证 | 跨年度整理产品、渠道、成本、资本与现金数据，输出证据候选账本 | 按核验方案审计，确认可登记事实，解释机制与替代解释 |

**Skill 固化稳定步骤，不固化旧答案。** 公司名称、报告年度、实际原始文件、当次研究问题与输出路径由任务合同给定；已经使用过的数字、页码、口径裁决和机制判断不能作为通用答案写进 Skill。任务二只允许提取时，Skill 不因能计算就擅自计算毛利率；任务四与第五次的计算也必须按各自合同执行。

项目级 Skill 的核心载体沿用 `.claude/skills/<skill-name>/SKILL.md`，必要时再增加脚本、参考资料和模板。这里说明的是任务方法与数据衔接，不要求学生另交完整 Skill 工程；Append2 已将 Skill 开发列为不计分的观察性拓展。

Append3 说明文件职责，Append4 说明权限边界。原始材料只读，候选与修正进入过程底稿，证据账本写入受核验约束，阶段成果保留支持边界。Skill 稳定运行不能自动扩大允许材料、改写原始文件或自行确认 Fact。

> [!note] 信任改变什么
> 信任改变复核方式和处理规模，不改变证据标准与人的责任。原型阶段人工全量核验；稳定批量阶段可按合同采用常规字段抽查、关键字段与异常重点复核，但拟进入重要结论的证据必须完成相应人工核验。

### 10.1.3 稳定规则与停止条件

| 工作 | 可以固化的规则 | 必须停止并交回人工处理的情况 |
| --- | --- | --- |
| 结构化提取 | 按商品、地区、渠道分解；保留收入、成本、报告期、单位、主体及来源位置 | 表头或跨页不清、收入成本错列、脚注限制不明、合计异常 |
| 口径检查 | 保留各候选，比较指标边界、报表主体、合并范围、期间、单位与用途 | 营业总收入与营业收入混淆、合并与母公司冲突、净利润归属不清 |
| 变化复算 | 代入已选本期与比较期，保留公式、结果与舍入 | 比较基数为零、定义或合并范围改变、单位币种不同、重述或不可比未裁决 |
| 派生指标整理 | 按既定公式连接已核验输入和相应分析范围 | 分母或范围不明、金融与实体经营混配、重复扣减营运资本 |
| 证据候选账本 | 保留来源、定位、口径、人工核验状态、当前判断状态及缺口 | 无原始指针、未经确认自行标为 Fact、用旧结论填补 Unknown |

自动检查能够发现字段、格式、公式或勾稽问题，不能证明记录与原文一致，也不能选择经济机制。停止并保留 Unknown，是稳定流程的组成部分。

### 10.3.1 机器可读首先意味着沿用稳定字段

Append2 已给出提取、口径与变化底稿的稳定字段，主课件 6.3 已给出研究问题、管理层主张、原始材料、证据位置、Fact、Interpretation、Unknown、反证条件与下一步。本稿沿用这些中文字段；如脚本需要英文键，应作一对一映射，不重新命名专业概念或改变现有账本结构。

| 字段组 | 沿用的字段 | 机器处理规则 |
| --- | --- | --- |
| 任务与材料 | 研究问题、原始材料与版本、材料边界、报告期 | 接收任务 2—4 实际成果，保留来源任务和版本 |
| 原始记录 | 分解维度、原文项目名称、营业收入、营业成本、单位与币种 | 原值与原始名称不覆盖；空白、破折号与零分别保留 |
| 口径记录 | 候选编号、指标边界、报表主体、会计口径、报告期或时点、采用与排除理由 | 合并、母公司、产品、渠道和金融活动范围分别记录 |
| 来源指针 | PDF 页码、报告页码、章节、附注或表名、证据编号 | 一条数字或主张能返回具体原始位置；主题编号不能代替记录编号 |
| 计算记录 | 本期数、比较期数、比较基数、公式、代入值、结果、舍入规则 | 原始输入与派生值分开；单位转换保留过程，不直接改原值 |
| 核验记录 | 人工核验状态、核验人、核验位置、修正内容 | 状态沿用“待核验／核验通过／核验未通过”，不能由 Agent 自行宣布通过 |
| 判断记录 | 当前判断状态、Fact、Interpretation、Unknown、合理替代解释、反方证据、支持边界 | 使用 Fact / Interpretation / Forecast / Decision / Unknown，不新设第六种判断类型 |
| 叙事接力 | 可观察变量、反证条件、后续验证、下一步 | 可补充“叙事层次”字段标记第一层或第二层，但证据编号保持连续 |

人工核验状态与当前判断状态不同：前者说明有没有回查并通过核验，后者说明该记录是事实、解释、预测、决策还是未知项。派生计算只是处理方式；使用未核验输入得到的算术结果，不能因公式正确就成为 Fact。

若向 CSV 或其他结构化格式导出，一行只表示一个实际披露的记录组合，保留公司、年度、指标、范围与分类。产品和渠道若未交叉披露，不根据两个汇总维度制造“产品×渠道”事实。记录冲突、重述、被排除候选及停止计算的原因，不静默删除异常。项目已有字段名称与结构优先；本表是对照要求，不另建平行数据体系。

| 呈现位置 | 示例用途 | 必须共享的内容 |

正文可以采用“可核验问题—证据要求（变量、方向、时点、口径）—反证条件”的课件表达；底稿保存原始指针、公式和核验记录。文章不必把全部字段摆在每段中，但任何重要判断都应能返回底稿。

### 10.3.3 批量处理后的检查

| 检查 | 具体要求 | 不能通过时 |
| --- | --- | --- |
| 原值与单位 | 保留原表数值、单位与币种，换算可复算 | 回查原表，不按数值大小猜单位 |
| 分类与合计 | 商品、地区、渠道按同一维度核对；总额与分母明确 | 记录差额，不强行使不同范围相等 |
| 比较列与重述 | 本期与比较期定义、主体及单位可比 | 回到口径裁决，不能调整则 Unknown |
| 量价及单位经济 | 收入、营业成本与销量属于同一期间和产品范围 | 停止相应派生计算，不补虚构销量 |
| 再投资与现金 | 经营范围一致，CFO 已反映的营运资本变动不再扣减 | 修正公式与相关叙事，保留原错误记录 |
| 生产与销售滞后 | 投入、成熟与销售观察窗口有依据 | 标记观察不足，不用同年相关代替效果 |
| 证据核验与状态 | 重要事实有原始指针及人工核验，解释保留替代原因 | 候选继续留在过程底稿，不进入正式事实 |

D01—D17 也遵循这些要求。Append5 列示的 T 编号提供任务接力指针，本次上传材料没有替代原始年报或完整工作台账本。

### 10.4 必须保留的硬缺口

行业销量的统计断点、财务公司现金流无法完整分拆、维持性与扩张性 Capex 无法明确区分、基酒库龄或成本结转信息不足，都可能是正式分析的边界。

处理方式应是标记 Unknown、说明影响、缩小可支持结论的范围，并列出所需证据，而不是通过混用口径、主观比例或未经核验的 Agent 输出制造确定性。

### 10.5 最终收束

> 完成十年面板后，再把长期证据压缩为一份商业模式叙事。目标不是再次证明“茅台品牌很好”，而是形成一套财务报表和经营数据能够支持、限制和反驳的解释。
>
> **先用财报还原企业如何运转，再用商业模式框架解释它为何成立。**

## 附录 B：本次重要的逻辑与口径修订

本次整理保留了原稿数据、关键机制、数据缺口和教学意图，同时对以下可能误导理解的表达作了处理。

| 原文需要理顺之处 | 整理后的处理 | 原因 |
| --- | --- | --- |
| 原始材料提出五个环节，后续材料坚持课程四环节 | 正式主线保留收入、成本、资本投入、现金流；资本配置作为延伸 | 同时保留分析完整性和课程结构一致性 |
| 两套框架一度被表述为二选一，之后又要求连续使用 | 区分取证阶段与综合写作阶段，形成两份连续成果 | 不是平行任务线，而是从证据到解释的递进 |
| 盈利模式被树形结构挂在现金流下 | 明确其贯穿四环节 | 避免把盈利模式误认成仅仅是现金转换 |
| 将扣除部分费用后的利润直接写成营业利润 | 改为“经营利润小计〔分析口径〕”，要求与报表其他项目衔接 | 防止漏掉财务费用、投资收益及其他适用项目 |
| 将资本投入与成本并列后直接说“扣除后形成经营利润” | 区分资本化投入、费用确认、折旧摊销、存货结转与现金支出 | Capex 不能直接作为当期经营费用扣减 |
| 收入变化直接写成数量、价格、产品与渠道效应之和 | 增加多产品多渠道公式，要求说明分解方法、交互项与未解释项 | 避免重复归因或将分析框架当成未经定义的恒等式 |
| “市场需求量”与行业销量分母未充分区分 | 使用同口径市场总销量与数量份额，并单列需求假设 | 观察到的销量不等于潜在需求，也不能与产量、金额混用 |
| 从 CFO 出发再次扣减营运资本增加 | 取消重复扣减，分别列示 CFO 起点与 NOPAT 起点的计算关系 | CFO 已反映相关经营现金变动 |
| 资本配置使用不完整的近似现金恒等式 | 先用 CFO＋CFI＋CFF＋汇率影响勾稽，再拆用途 | 避免遗漏融资、利息、资产处置等活动，以及现金口径差异 |
| 财务公司调整被写成简单减项 | 明确为对合并 CFO 的带符号净贡献，并考虑合并抵销及披露限制 | 单体现金流不自动等于合并贡献 |
| 批发、直销和数字化平台可能被当作三种互斥渠道 | 按实际披露归类，数字化平台不自动另成一级类别 | 防止重复统计渠道收入 |
| 以 FCF 稳定覆盖净利润作为普遍判据 | 改为联合考察现金转换、必要再投资和后续资本回报 | 合理增长投入可能降低当期 FCF，不能据此直接否定经营质量 |
| 同年再投资与当年收入直接对应 | 增加成熟周期、多年累计及滞后检验 | 匹配长周期生产和资本回收特征 |
| 原稿“已核验”容易被误认为本次重新核验 | 统一注明为原稿证据状态，正式使用须回查原始年报 | 区分材料整理与独立事实核查 |
